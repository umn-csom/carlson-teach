# Theme directory

Use this directory to add additional themes to your site. To get started on building a
site theme, you can copy the `umn_subtheme` directory from `sites/all/themes`. Rename
the subtheme directory, the `umn_subtheme.info` file and any instances of 
`TEMPLATE_preprocess_*` in `template.php` (i.e. change to `themes/my_subtheme/my_subtheme.info`
and `template.php` functions to `my_subtheme_preprocess_*`).
